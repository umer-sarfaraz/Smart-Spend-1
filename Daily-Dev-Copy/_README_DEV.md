# SmartSpend — Daily Dev Copy

This folder is an **automatically evolving copy** of the SmartSpend app.

- **Your live app stays untouched** in the parent folder (`expenses mobile app`). Nothing here affects it.
- **A scheduled task improves this copy a little every day** — fixing glitches, filling gaps, and applying redesign work inspired by leading expense/budgeting apps.
- **Every change is logged** in `CHANGELOG_DEV.md` (newest on top) so you can see exactly what was reviewed, what was found wrong/missing, and what was changed each day.
- A full pre-redesign backup also lives in `../Backups/`.

To preview this copy yourself: open a terminal here and run `npm install` then `npm run dev`.
